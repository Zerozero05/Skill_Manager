# v0.2.11（候选，未正式发布）

本候选修正说明更新长期停留在待办，以及旧自动文件范围和带参数脚本引用的误判。正式发行与下载仍为 [v0.2.10](https://github.com/Zerozero05/Skill_Manager/releases/tag/v0.2.10)；本文件不是公开发行完成声明。

## 本次变化

1. **说明检查完成后退出待办。** 只有说明或管理信息变化时，检查完成后按“内容一致”显示并使用相同排序，兼容保留原始 `docs_updated` 状态。“最近检查”折叠摘要只统计本轮实际发生的说明／管理信息指纹变化，重复检查无新变化时计0。不新增页面、已读按钮或持久逐Skill游标。
2. **真实问题继续处理。** 运行内容差异、必要文件缺失、未纳入范围的本地文件、来源歧义和检查异常仍留在待办，原因与主操作指向实际问题。完成项立即退出批量选择；仍待处理但被搜索或分页隐藏的选择保持。
3. **有证据才修正旧自动范围。** Hatch Pet已知旧自动确认范围可由28项修正为目录清单声明的23项，条件是可信目录清单、新鲜的本地与远端完整范围逐项一致，以及记录确属旧自动范围。人工确认／调整的范围不变，许可证、必要脚本与参考资源继续保留，不删除原文件，不按数量或文件名猜测。
4. **脚本路径和参数分别识别。** 引用如 `scripts/run.py --mode preview` 时，核对实际脚本入口，不将参数拼进文件名。真实必要文件缺失或无法读取仍会提示。
5. **选择工具按需展开。** 单项可直接重新检查；多项通过“批量选择”展开复选框与分组工具条，保留全选、清空、退出及Ctrl+A/Esc。选中数量独立显示，执行操作靠右，窄窗口自动换行。

## 使用与兼容

- 文件范围由管理器默认识别，是检查、更新和上传使用的管理记录；“调整文件范围”用于特殊情况人工核对，不是Skill运行开关。能否执行取决于实际文件、客户端和运行环境。
- 本次ZIP可选勾选、长期文件范围及原文件保留继续分开处理；不复制Skill来源、不修改人工范围或自动覆盖本地内容。
- 继续保留搜索、筛选、选择快捷键、来源错误、三主题、大字号、缩放、多标签及单滚动行为；不新增依赖。
